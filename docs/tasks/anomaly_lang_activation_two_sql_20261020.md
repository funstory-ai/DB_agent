## 初始需求

两段 SQL 都被当成「分语言激活」，结果差很多。要说明差在哪。

## 口径

| 项 | 第一套 | 第二套 |
|----|--------|--------|
| 表 | `imm_device_native_language_without_fb` | `user_behaviour` LEFT JOIN `vw_device_user_language_map` |
| 时间 | 不限；按 `install_day` 的月 | `created_ts` 2025-10-01～2026-10-01；按事件月 |
| 人数 | `device_id` | `hybrid_id`（登录用户 `U_`+userid，未登录 `D_`+device_id） |
| 语言 | 仅目标语累计，无界面语兜底 | 主表 `imm_device_native_language`（含兜底），按 hybrid 加总 cnt 取最大；只留 zh-CN / zh-TW / ja / ko / en |
| 事件 | 无 | `translate_page` 且 `is_new_user_today='1'` 且 `ex_char_arg10='com'` |
| 外层 avg | 无 | 内层已按月一行，`avg(dau)` 等于该月去重人数 |

`ex_char_arg10`：插件 `format_self_report.ts` 写 `isCNPlugin() ? "cn" : "com"`（国内版 / 国际版）。

without_fb 任务 `update_imm_device_native_language_without_fb` 为 20:00 UTC；目标语累计 `update_imm_user_target_lan_stats` 为 21:00 UTC。当天第一次带目标语翻译的设备，without_fb 跑的时候累计表还没有这一天。

## 抽样复核

通过。三桶相加 8,879+15,356+1,516=25,751。只译当天的几乎都不在 without_fb（后来又译的 320/15,356）；在表里的几乎都有之后的目标语翻译（8,522/8,879）。

全年激活与版本字段拆分是两次查询：2026-09 简中 com 都是 529,536。日表简中激活 625,586 对不限版本的设备数 637,922，差约 2%。英语主表 829,237 对 without_fb 62,255，和日表英语新装 807,692、激活 56,077 是同一侧缺口。
