## 关键发现

1. **功能结构**：绝对主力是 EPUB 电子书翻译（84.3%）；其余为网页/未归类/少量字幕。工单质疑的正是其主力功能。
2. **异常已定位（回应 Q4）**：EPUB 单请求文本段大小在 9 月底→10 月持续变大，后期书每页 token 上涨的源头是 **文本分组/分块方式变化**（段更长），非模型切换或功能暴增。
3. **无系统提示膨胀（回应 Q1）**：input 体量小且无大请求，账本不支持"系统提示每条重复计"。
4. **无重复计费（回应 Q3）**：请求对全唯一。
5. **额度归属**：全部走订阅 AI 计数器，未走任何购买的流量包。
6. **量级**：窗口内以 105.0M token 排全量第 23 / 684,021 活跃用户（前 0.003%）——极重度头部。
7. **模型**：EPUB 以 Claude Haiku（4.5 与 5.5 via OneRouter）为主，辅以 Gemini-3-Flash / GPT-6-Luna / Grok / GLM / DeepSeek / Qwen 等正常路由；与用户所述"Claude Haiku 5.5"一致。
