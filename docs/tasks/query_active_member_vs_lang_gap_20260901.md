# 有效会员总数 vs 按语言有效会员对不上

- **需求编号**: T026
- **规范大类**: `query`
- **状态**: ✅ 已完成
- **日期**: 2026-09-01
- **定稿 SQL**: `sql/reports/query_active_member_vs_lang_gap_20260901.sql`（对账汇总，只读）
- **映证**: T008 月末有效会员（`sql/reports/task7_month_end_active_members.sql`）

## 需求

两边数字对不上：
1. **总数**：task7 月末有效会员口径
2. **按语言**：`imt_device_regional_test`（9 语 + rn=1）→ `deviceinfo` → 订单，仅 `amountpaid>0`

问：**除电商部分外，还差多少？**

截面固定：**2026-06 月末**（task7：`as_of = 2026-07-01`）。

## 口径差异（已确认）

| 项 | task7（T008） | 用户按语言 SQL |
|----|---------------|----------------|
| 会员单 | `amountpaid>0` **或** onetime **或** `ordertype=code` | 仅 `amountpaid>0` |
| 时间界 | `createtime < as_of` 且 `cover_end >= as_of` | `createtime <= as_of` 且 `cover_end >= month_end` |
| 主体 | userid 去重 | device→userid，再 `GROUP BY` 语言（可重复） |

「电商」= onetime 兑换码 + `ordertype=code`（P024）。

## 实测结果（2026-06 月末）

| 指标 | 人数 |
|------|------|
| task7 总有效会员 | 52,176 |
| task7 仅现金（amountpaid>0） | 50,113 |
| 纯电商有效（有 onetime/code 覆盖、无现金有效单） | 2,063 |
| 按语言 GROUP BY 各语相加 | 49,326 |
| 按语言路径去重 userid | 46,990 |

### 除电商后还差多少

以「各语相加」对比（更贴近用户算法）：

- 总缺口：52,176 − 49,326 = **2,850**
- 电商解释：**2,063**（纯电商 0 人进得了语言 SQL）
- **扣电商后仍差约 787**（50,113 − 49,326）

以「去重 userid」对比：扣电商后仍差约 **3,123**。

### 现金有效但进不了语言路径（3,252）归因

| 原因 | 人数 |
|------|------|
| 无 `deviceinfo` | 1,572 |
| 有设备但无 `regional_test` 行 | 945 |
| 语言不在 9 语列表 | 735 |
| 有设备且在 9 语仍对不上 | 0 |

另：各语相加 − 去重 = **2,336**（同一 userid 多设备多语言重复计数）。边界微差：用户边界比 task7 约多 163 人。

## 需求覆盖对照

| 条目 | 落点 | 状态 |
|------|------|------|
| 总数 vs 按语言对不上差多少 | 对话结论 + 定稿对账 SQL | ✅ |
| 除电商外还差多少 | ~787（各语相加）/ ~3,123（去重） | ✅ |
| 差额归因 | 电商 / 无设备 / 无 regional / 非 9 语 / 多语言重复 | ✅ |
| 对齐版按语言定稿交付 | 用户未要 | 不做 |

## 结论摘要

对不上主因：（1）语言 SQL 不含电商；（2）挂不上 deviceinfo/regional/9 语；（3）`GROUP BY` 语言会重复计数，不能与 userid 总数直接加总比对。
