## 与上版（T084, asof 10-23）的对比与历史周分母漂移

- 各周切片人数加总 = 汇总：新墙 15,234+69,318+71,830=156,382；老墙 14,221+63,254+66,171=143,646，完全一致。
- **历史周分母（10/12–18）小幅收敛**：本版新墙 69,318 / 老墙 63,254，较 T084 的 69,354 / 63,298 各缩约 0.05%。这正是上一轮排查已确认的机制——剔老号层依赖 `imt_deviceinfo` 设备↔userid 关联，该关联会随用户后续认证持续回填，导致历史周分母在刷新时小幅收敛（通常 <0.2%）。**属测量噪声，主结论（新墙 f–j vs 老墙 a–e 转化差）不受影响。**
- 10/19–22（上版未满段）在本版已并入完整 10/19–25 周，故不可直接与上版同名切片对比；新墙累计付费 292 vs 上版 223 主要因观察窗拉长（多罩 10/23–25 三天）自然上升，非转化率变化。
