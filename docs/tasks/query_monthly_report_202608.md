## 沉浸式翻译2026年08月核心数据

### 1、月活、日活继续下降，低谷加深

沉浸式翻译2026年08月月活用户448.7万，比07月471.1万下降22.4万，单月下降4.7%；相比05月490.0万下降41.3万。
日活用户均值67.9万，相比07月74.0万下降8.2%；
日活峰值为76.8万，相比07月83.2万下降7.7%。

### 2、总用量继续回落，网页翻译降幅仍显著大于视频

08月翻译总事件32684万个，比07月35649万个下降8.3%；
08月网页翻译14507万个，单月下降13.1%；
08月视频翻译17726万个，单月下降4.2%。
人均网页翻译32.3（07月35.4），人均视频翻译39.5（07月39.3）。
整体来看，08月总用量相比03月高点46114万个累计下降29.1%，环比仍在回落。其中网页翻译继续明显下降，仍是总用量下滑的主要来源；视频翻译总量继续小幅回落，人均用量与07月基本持平（39.5 vs 39.3），视频需求相对稳定。

### 3、收入高位回落后趋稳，单月净收入为263.6万

07月已自618高位回落，08月单月净收入为263.6万，相比07月265.9万略降0.9%，环比基本持平。
同比25年08月204.1万增长29.2%，收入同比仍保持增长。
注：08月自建MRR为329.7万，环比增长2.3%；Stripe MRR为288.1万，环比增长1.9%；有效订阅用户为42076，环比增长1.6%。本月自建MRR、Stripe MRR与有效订阅均小幅回升；订阅收入趋势仍可重点参考自建MRR数据。
