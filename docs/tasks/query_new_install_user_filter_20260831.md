## 定义（账号级，锚点 = `min(installtime)`）

同时满足才算 **干净新装用户**：

1. **锚点前无真金付费（容差 5 分钟）**  
   不存在 `finished` 且 `amountpaid>0` 且 `createtime < install_anchor − 5min` 的订单  
2. **无「现金早于账号创建」**  
   不存在现金单 `createtime < userinfo.createtime − 5min`  
3. **账号相对安装不能太老**  
   `date_diff(day, userinfo.createtime, install_anchor) < 30`  
   （挡「老号迟补上报扮新装」、且安装前未必有订单的老号）

**不做：** 用 `iospay_renew` 过滤；扫行为表；把口径改成新注册。

## 用 T021 验证（2026-08 min(install)）

| 验证集 | 结果 |
|--------|------|
| 安装前现金 gap **≥30 天**（29 人） | **29/29 被剔**（规则 1） |
| 安装前现金 **≤5 分钟**（27 人） | **24 保留**；仅 3 人因规则 3（账龄≥30）一并剔除 |
| gap 6min～29 天 | **全部剔除**（规则 1） |
