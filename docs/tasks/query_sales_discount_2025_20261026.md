# 2025 打折销售活动清单

- **需求编号**: T087
- **规范大类**: query

- **定稿 SQL**: `sql/reports/T085_sales_discount_2025.sql`

- **交付物**: `output/sales_discount_2025_campaigns.xlsx`

## 初始需求

查去年（2025）都做过哪些销售活动。标准：本来标价 588 的年费会员（或其他费用）打折来做销售活动。

## 口径

| 项 | 定义 |
|----|------|
| 数据表 | `immdata.imt_subscriptiongoodsorder`（订阅商品订单，业务库只读副本，日更） |
| 过滤 | `COALESCE(isdeleted,0)=0`；`orderstatus='finished'`；`COALESCE(amountpaid,0)>0` |
| 币种 | `UPPER(currency)='CNY'`（其他币种 amount/amountpaid 单位不稳，P008，不纳入） |
| 时间窗 | `createtime` ∈ [2025-01-01, 2026-01-01) |
| 标价 | `amount`（元，decimal） |
| 实付 | `amountpaid/100`（元；amountpaid 为最小货币单位整数，P008） |
| 打折（可度量） | `amountpaid/100 < amount*0.98` |
| 活动标识 | `couponname`；有券号=命名活动，无券号但打折=「未命名折扣/直接降价」 |
| 主体 | 订单行；付费人数 = `COUNT(DISTINCT userid)` |

**关键发现（P043）**：`amount` 是产品**标准标价**，`amountpaid/100` 是活动折扣后**实际成交**，折扣可对所有 CNY 订单直接度量（`(amount-amountpaid/100)/amount`）。用户所说「年费标价 588」在 2025 实际为 **579.6**（疑为更早/取整口径）；其他标准价：月费 69 / Max年费 1599 / Max月费 199 / 家庭版约 1244.88。

## 主要结论

- 2025 CNY 付费订单约 13.7 万，其中打折/活动订单 **14,910**（命名活动 13,133 + 无券号直接降价 1,777）。
- 命名活动按 `couponname` 聚合并分类：大促节点（618 / Double 11 / 夏日特惠 / 中秋 / 圣诞新年）、渠道达人合作（dedao / b站达人 / 有赞拼团 / 小宇宙 / 英语达人等）、通用优惠券（专属优惠 / 5% OFF / 85折 / Limited-Time Coupon）、续费优惠（Renewal Exclusive Discount）、团购家庭（Family Plan Sale）。
- 折扣幅度示例：618 年费 −32%、Double 11 年费 −32%（¥404 vs ¥579.6）、中秋 Max 年费 −45%、夏日特惠月费 −85%（¥9.99）、有赞拼团月费 −99%（¥0.01）、Renewal −30%。
- 月度分布：活动集中在 3 月起，6 月（618）、8 月（夏日/暑期）、10–11 月（中秋/Double 11）、12 月（圣诞新年）为高峰。

## 抽样复核（P019）

- 命名活动峰值月份与名称吻合：618→6月、Double 11→11月、Christmas→12月、Summer Sale→8月、Mid-Autumn→9–10月。✅
- 抽样「未命名折扣」：年费 579.6→539.95/405.72、月费 69→65.55，确为降价。✅
- 低均值活动（夏日特惠 ¥10.14、有赞拼团 ¥6.34）经抽样确认为真实深折（月费 ¥9.99 / ¥0.01），非单位错误。✅
