## 初始需求

查今年做过哪些销售活动。指订单实际收入比标准收入打了折的。

## 口径（草案）

| 项 | 定义 |
|----|------|
| 时间窗 | `createtime` ∈ [2026-01-01, 2026-10-22)（今年至查询日；日更水位见 P043） |
| 订单 | `imt_subscriptiongoodsorder`；`COALESCE(isdeleted,0)=0`；`orderstatus='finished'`；现金 `COALESCE(amountpaid,0)>0` |
| 标价 | `amount`（小数，P008） |
| 实付 | `amountpaid/100`（最小货币单位，同订单币种，P008） |
| 打折 | 实付 < 标价 × 0.98（避开分位舍入） |
| 活动标识 | `couponname` / `promotioncodeid`；无名则按折扣幅度、商品、时间簇 |
