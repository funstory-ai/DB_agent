## 口径

| 项 | 定义 |
|----|------|
| 时间窗 | 今年 **2026-10-25 ~ 2026-11-12**（19 天）；去年同期 **2025-10-25 ~ 2025-11-12**（19 天，同月日一一对应）。均为**北京自然日**：订单 `createtime + 8h` 取 `date_trunc('day', ...)`。WHERE 用对齐的 UTC 粗边界保分区裁剪：今年 `[2026-10-24 16:00:00, 2026-11-12 16:00:00)`、去年 `[2025-10-24 16:00:00, 2025-11-12 16:00:00)`，两段以 OR 拼接，绝不把中间一年扫进来 |
| 分母 / 分子 | 分子 = 付费订单实付金额折人民币（CNY），按「北京日 × 地区桶」汇总。另出付费单数、`COUNT(DISTINCT userid)` 付费用户数作交叉校验。本题是收入总额，**无分母、非转化率** |
| 主体 | 付费订单 `userid`（P013）；地区归属挂在 userid 上，不按设备把同一账号拆成多笔 |
| 付费定义（P013） | `imt_subscriptiongoodsorder`：`COALESCE(isdeleted,0)=0` + `orderstatus='finished'` + (`COALESCE(amountpaid,0)>0` 或 `LOWER(ordertype)='code'` 或 `subscriptiontype LIKE 'onetime%'`)。兑换码 `amountpaid` 常为空 → 计 1 单、金额计 0（沿用 T107，不臆造金额） |
| 地区归属（按 IP） | `real_geo` 为 2 位 ISO 国家码（**IP 国家**，非母语 `imm_device_native_language`、非账号注册地）。链路：订单 userid → `imt_deviceinfo.deviceid`（`isdeleted=0`）→ `imm_regional_activation` 按 userid 取**全历史出现次数最多的 real_geo**（`ROW_NUMBER ... rn=1`）。分 SG / MY / NO_GEO（取不到，主为移动端）/ OTHER 四桶；SG+MY 合计 = SG + MY |
| 金额与币种 | `amountpaid` 为最小货币单位（分）；`(amountpaid/100) × exchangerates.exchangerate` 折人民币（CNY=1 基准）；`UPPER(currency)` 归一后 join。汇率匹配不到按 **P046** 处理（不得置 0 漏算），本次先抽样核对未匹配币种量级再定 |
| 两年可比 | 两年共用**同一套全历史主导国家映射**（沿用 T107d），使同比只反映收入变化、不被逐年 VPN 噪声干扰。⚠️ 已知限制：映射含 2026 年地理信息，对去年订单有轻微前视归属；按用户确认沿用，与历史交付同口径 |
| 移动端缺口（P037） | iOS/Android 的 `device_id` 大多不在 `imt_deviceinfo` → 归 NO_GEO，故 SG/MY 收入为**下界、非全量**；NO_GEO 单列展示，禁止摊进 SG/MY |
| 数据完整性 | **2026-11-12 是当天**：业务表经 `H:\imt_data_synch` 北京每天 01:00 日更、副本停在约 01:xx 是正常水位（P043，不是同步故障）→ 该日**不完整**，表内标注且不参与同比结论；去年同期对应日为完整日 |
| VPN 噪声 | 单用户 `real_geo` 高度碎片化（T107 抽样证实），主导国家已稀释偶发 VPN/漫游；SG/MY 绝对值带噪声，且日粒度样本更小（T107b 周版仅约 ¥2.5 万/周）→ 结论以窗口合计与两年对比为主，不以单日尖峰下判断 |
| 交付 | 多 sheet Excel：`逐日收入_今年`、`逐日收入_去年同期`、`同比对照`、`分币种`、`结论与口径`。canonical `scripts/export_sg_my_daily_revenue_yoy.py --start --end`（自动推导去年同月日窗口；交付须带 `WF_TASK=T112`） |

## 关键结论

**完整日 = 10-25 ~ 11-11 共 18 天**（今年 11-12 为当天、订单水位仅到北京 01:02，剔除；去年对应日完整）。全窗口 19 天另作对照。

| 指标 | 今年 2026 | 去年 2025 | 同比 |
|------|----------:|----------:|-----:|
| SG+MY 合计 | ¥88,578.75 | ¥88,519.42 | **+0.1%** |
| SG | ¥74,427.20 | ¥78,958.02 | −5.7% |
| MY | ¥14,151.55 | ¥9,561.40 | +48.0% |
| NO_GEO（移动端测量缺口） | ¥148,189.05 | ¥53,363.76 | **+177.7%** |

- 地理可见部分「SG+MY 同比基本持平」，但**结构分化**：SG −5.7%、MY +48.0%（MY 基数小、日粒度波动大，勿当强趋势）。
- ⚠️ **不能把 +0.1% 读成两地真实总量持平**：同期 NO_GEO 由 ¥5.34 万涨到 ¥14.82 万（+177.7%），SG+MY 占「SG+MY+NO_GEO」比由 **62.4% 降到 37.4%**。移动端设备号大多不在 `imt_deviceinfo`（P037），缺口扩大意味着更多付费无法归到任何国家，地理可见部分被稀释、真实两地总量更可能被低估。这是 T107 已提示的**测量缺口**，不是业务增减的结论（P043）。
- 全窗口（含今年 11-12 不完整日）¥89,470.95 vs ¥91,670.49（−2.4%）仅作对照；11-12 当日今年 ¥892.20 vs 去年 ¥3,151.07（−71.7%）是数据水位差，不是收入下滑。
- 日粒度噪声大（SG+MY 日均约 ¥4.9k），逐日同比在 −62% ~ +64% 间摆动，单日尖峰/谷值不解读。
