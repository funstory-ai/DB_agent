## 抽样复核（诊断证据）

全部为独立 SQL（设备级、不做主体映射），未重跑 T111 全量交付脚本。除特别说明外，cohort = 北京日 2026-10-20、D+7 = 2026-10-27、仅 `ex_char_arg10='com'`；与 T111 抽样复核第 3 条同锚点同粒度。

**1. 先复现被复核的格子（P044）**：设备级分组 D+7 `home_show` = 用过 286/4,527 = **6.32%**、未用过 2,550/7,977 = **31.97%**、全体 2,836/12,504 = **22.68%**，与 T111 抽样复核第 3 条逐格一致。T111 主交付 30 天成熟合计（主体级）7.27% / 32.08% / 22.91%；本次独立设备级 30 天成熟合计 = 6,690/100,070 = **6.69%** / 53,591/181,449 = **29.54%** / 全体 60,281/281,519 = **21.41%**，高出的 0.6 / 2.5 / 1.5pt 来自 userid 归并把同账号多设备、跨设备回访合并，方向与量级一致。

**2. 排除口径假象（4 条独立路径，差异都不消失）**：
- 换活跃代理：D+7 用「任意事件」判定回访，用过 301/4,527 = **6.65%** vs 未用过 2,707/7,977 = **33.93%**；「有任意事件但无 `home_show`」仅 14 / 155 台，「进过 Tab2 但无 `home_show`」**0 / 0 台** → `home_show` 对这两组没有系统性漏报，不是埋点代理失效。（此 CTE 不限 edition，比限 com 口径多 1~2 台，<0.03pt，不影响结论。）
- 换留存窗：D+1~D+7 **任一天**回访 = 用过 1,310/4,527 = **28.94%** vs 未用过 5,253/7,977 = **65.85%**；后 7 天平均活跃天数 0.60 vs 2.31 天、7 天内从未回访 71.1% vs 34.1% → 不是「精确单日窄窗」压低了低频组。
- 换版本分层：同版本内差异依旧 —— 2.6.10 用过 1,760→6.36% vs 未用 3,408→34.83%；2.6.12 用过 1,788→6.71% vs 未用 3,283→33.93% → 不是「老版本没有 Tab2、未用组全是老用户」。
- 换主体 / 进入方式：按账号主体（有账号设备）差异仍约 4 倍（10.75% vs 40.95%）→ 不是移动端 `device_id` 不稳定；按 `entry_type` 拆，被动 `app_open` 5.86%、主动 `tab_switch` 6.76%，都远低于未用组 31.97% → 不是被动进入混入。
- 稳定性：全窗 23 个成熟 cohort 逐日复算，用过组 5.88~7.53%、未用组 26.59~31.97%，**无一天反转** → 不是单日数据异常。

**3. 主因是人群结构（Simpson）**：按「cohort 日前 30 天 `home_show` 活跃天数」分层：

| 历史活跃深度 | 用过组 n（占比） | 用过组 D+7 | 未用组 n（占比） | 未用组 D+7 |
|---|---|---|---|---|
| 0 天（30 天内首见） | 3,268（72.2%） | **3.06%** | 1,282（16.1%） | **2.81%** |
| 1–3 天 | 944 | 7.42% | 2,396 | 13.65% |
| 4–10 天 | 202 | 27.23% | 2,068 | 34.04% |
| 11 天以上 | 113（2.5%） | 53.98% | 2,231（28.0%） | 66.47% |

**在「30 天首见」这一层，两组留存几乎相同（用过组甚至略高 0.25pt）**；整体差距主要来自用过组 72.2% 是新装/一次性设备，而未用组仅 16.1%、且 28.0% 是 11 天以上的老活跃设备。双向结构标准化（按设备年龄层加权）：按未用组结构标准化用过组 = **24.88%**（差从 25.65pt 缩到 7.09pt，解释 72.4%）；按用过组结构标准化未用组 = **8.05%**（差 1.73pt，解释 93.2%）。

**4. 设备内固定效应（把「人」固定住）**：全窗 30 天 167,546 台设备、281,519 个「活跃日」观测，同一设备自己比——
- 设备间混合口径：用过日 100,070 观测 → 6.69%，未用过日 181,449 → 29.54%（差 22.85pt）；
- 限定 15,382 台**同时有两类日子**的设备：用过日 21,040 → **21.75%**，未用过日 46,699 → **35.17%**（差缩到 13.42pt）；
- 设备级配对差（用过日−未用过日）**中位数 0.00pt**，均值 +3.75pt（被小样本设备的极端值拉高，以中位数为准），仅 19.0% 的设备为正；
- 再看观测日距设备首见 ≥7 天的成熟阶段：28.97% vs 40.21%（差 11.24pt）。

即：多数设备内部看不出「用了 Tab2 就不回来」，剩余 11~13pt 与「用过 Tab2 的日子集中在设备的低频/生命周期末段」这类选择效应纠缠，**仍是观察性对照，不能推断 Tab2 的因果作用（P043）**。

**5. 追加澄清（用户 11-13 追问「是不是功能留存 / 老用户留存低」）**：补一条不分 Tab2 的独立 SQL，直接按设备年龄测 10-20 cohort 的 D+7 App 留存 —— 0d 新设备 136/4,550 = **2.99%**、1-3d 397/3,340 = **11.89%**、4-10d 759/2,270 = **33.44%**、11d+ 老设备 1,544/2,344 = **65.87%**。**老设备留存约是新设备的 22 倍，方向是「老用户留存高」，不是低**。同时澄清两个不同口径：T111 Sheet4 的 2.76% 是 **Tab2 功能留存**（D+7 再次触发 `app_tab2_enter`）；Sheet5 的 7.27% / 32.08% 是 **App 级留存**（`home_show`），只按当日是否用过 Tab2 分组。正确链条为：不用 Tab2 的组多为有历史活跃的老用户 → 留存高；用 Tab2 的组 72.2% 是 30 天首见的新装/一次性设备 → 留存低。分组是人群标签，不是实验组/对照组。

**6. 合理性扫描**：所有比率在 (0,100%)；分组人数 4,527 + 7,977 = 12,504 = 当日 `home_show` 设备数，无重复计数或漏人；任意事件代理覆盖 430 万台 com 设备，不存在事件侧截断；分层样本量小的格子（用过组 11 天以上仅 113 台）只作辅助，不据此下单点结论。

## 主要结果

**结论：数字确定，但原来的读法容易误导。**

1. Sheet5 的 7.27% vs 32.08% 是**真实且稳定**的：8 条独立路径（同锚点复现、换活跃代理、换留存窗、按版本/账号/进入方式分层、逐 cohort 稳定性、全窗合计）都复现，不是 SQL 错误、主体映射、埋点漏报或单日异常。
2. 它**不能读成「Tab2 降低留存」**。分组是行为自我选择而非随机分组：当天进 Tab2 的设备七成是 30 天内首见的新装/一次性设备，未用组以稳定老用户为主；同年龄层内（尤其新设备层）差距基本消失，结构标准化可解释 72~93% 的差距 —— 典型 Simpson 悖论。付费对照 5.79% vs 0.20% 同理不可当因果（T111 已注明，本复核进一步坐实）。
3. T111 文档原写的「Tab2 D+7 低主要是 cohort 本身流失」方向正确，但当时依据只是「回访者中 34% 再用 Tab2」的间接推断；本次补上了直接的分层与设备内配对证据。
4. **交付处置**：T111 的 Excel 数字无需修订（口径定义与需求一致，分母同源）；需在 Sheet5 / 摘要标注「两组人群不可比、结构差异主导、勿作因果解读」。是否补一页分层诊断到 Excel，由用户决定；本次只做解释性复核，不改动已 `audited` 的交付文件。
5. 若要真正评估 Tab2 对留存的因果作用，现有埋点做不到：需要随机分流/灰度实验，或至少按设备年龄、账号状态、生命周期阶段做匹配后再比较，且仍无法排除使用意图的自选择。
