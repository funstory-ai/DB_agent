## 需求

算一下近一个月的试用转化率。

## 口径确认（开查前与用户对齐，P025/P032）

| 项 | 口径 |
|----|------|
| 分母 cohort | 近 30 天（NOW()-30d ~ NOW()）内**首次**产生试用单的账号（userid）；此前无任何试用记录（MIN(createtime) 落在窗内即保证无更早试用） |
| 分子（转化） | 该账号在「首次试用单之后（至 asof 当前）」任意一次**付费单**即算转化，累计、不限时 |
| 主体 | userid 全量（含老用户）；匿名单（userid 为空）剔除；**不**剔老号（P039 不适用本通用口径） |
| 试用（P013） | `finished` 且 `amountpaid=0` 且不是兑换码（排除 `ordertype='code'` 与 `onetime*` snap）；稳健写法，不只用 `ordertype LIKE '%trial%'` |
| 付费（P013） | `finished` 且（`amountpaid>0` 或 兑换码：`subscriptionday>0` 且 `onetime*`/`code`） |
| 交付形态 | 汇总数字（转化率 + 分子/分母 + 一句话结论），不落 Excel |

## 结果（asof=2026-10-27，窗 2026-09-27 ~ 2026-10-27）

| 段 | 首次试用人数 | 转化人数 | 转化率 |
|----|----|----|----|
| **ALL** | **16,520** | **2,050** | **12.41%** |
| W0（首试≥21天前） | 3,590 | 607 | 16.91% |
| W1（14–21天前） | 3,651 | 460 | 12.60% |
| W2（7–14天前） | 4,209 | 502 | 11.93% |
| W3（0–7天前，偏早） | 4,077 | 471 | 11.55% |
| W4（近 1–2 天） | 993 | 10 | 1.01% |

## 结论与证据（P043）

- 按确认口径，近一个月首次试用 cohort 的「到当前累计付费」整体转化率为 **12.41%**（16,520 → 2,050）。
- **该整体率被未成熟期结构性低估**：拆分首试周可见转化率随 cohort 越近期越低，最成熟周（W0，首试已 ≥21 天）达 16.91%，而最近周（W4，首试仅 1–2 天前）仅 1.01%——这是「累计付费 + 近 30 天 cohort」的固有测量偏差，非计算错误（已抽样验证：转化用户均满足 首试<付费；W4 首试时间确为 10-25~10-26）。
- 因此「真实（成熟后）试用期转化」更可能落在 **15%–17%** 区间；**12.41% 是受近 1–2 周未成熟 cohort 拉低的当下读数**。若要稳定读数，建议改用「首试已满 ≥21 天」的固定成熟 cohort（约 16.9%）作为主指标。
- 猜测标注：W1–W3 的 ~11.5%–12.6% 略低于 W0 的 16.9%，可能因近期试用流量质量/支付入口变化或仍在转化途中；尚缺对近 4 周试用来源的逐周归因（未查埋点/支付后台），不能据此判定趋势。
