# 简中（zh-CN）占比估算

- **需求编号**: T083
- **规范大类**: query
- **状态**: ✅ 已完成
- **日期**: 2026-10-23
- **定稿 SQL**: `sql/reports/query_zhcn_share_20261023.sql`
- **数据水位**: `ads_language_daily_overview` / `imm_device_native_language` 北京日更；`user_behaviour` 约 10B 行，按 `created_ts` 限窗

## 需求

给定背景：平均日活 73W、网页翻译日均 500W。估算「简中」占比（占用户 / 占翻译量）。

## 口径

- **简中代码**：`zh-CN`（来自 `imm_device_native_language`；target 优先、否则 interface fallback，与 DAU 总览同源）。
- **DAU 口径**：`ads_language_daily_overview` 近 30 个北京日，各母语 `SUM(dau)` 累计占比（DAU 加权≈日均占比）。
- **网页翻译量口径**：`user_behaviour` 中 `event_name='translate_page'` 近 14 天事件，LEFT JOIN `imm_device_native_language` 按设备归属母语，计算事件占比。
- **对照锚点**：总 DAU≈73W（周末~54W/工作日~77W，均值代入）、网页翻译≈5.09M/天（与 500W 锚点吻合）。

## 结果（2026-10-23 跑）

| 维度 | 简中 zh-CN 占比 | 备注 |
|------|----------------|------|
| **DAU（用户）** | **85.9%**（0.8586） | 近 30 日累计 DAU 加权 |
| **网页翻译量** | **87.5%**（0.8746） | 近 14 日 translate_page 事件 |
| 整体中文（zh-CN+zh-TW+zh-HK） | DAU 92.8% / 翻译量 93.3% | 繁中 zh-TW DAU 6.78%、翻译 4.71% |
| 简中占「中文用户」比例 | 92.7% | zh-CN / (zh-CN+zh-TW+zh-HK) |

- 网页翻译量中 `UNKNOWN`（设备未命中母语表）未进 top20，覆盖率可忽略，占比可信。
- 由 500W/天 × 87.5% ≈ **简中网页翻译 ≈ 4.4M/天**。

## 抽样复核（P019）

- 两个独立口径（DAU 总览表 vs 行为明细 JOIN 母语表）结果高度一致（85.9% vs 87.5%），互相印证，无假零/串组。
- 翻译量总事件 71.3M / 14d ≈ 5.09M/天，与用户给的 500W 锚点一致 → 两表与锚点同源可靠。
